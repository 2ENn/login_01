# ต้นแบบหน้าจอระบบ Single Sign-On (Prototype)

ต้นแบบหน้าจอ (front-end mockup) สำหรับระบบ SSO ใหม่ ใช้ดูหน้าตาและลำดับการใช้งานเท่านั้น
**ยังไม่ได้เชื่อมต่อ backend, ฐานข้อมูล หรือระบบยืนยันตัวตนจริง** ข้อมูลที่กรอกไม่ถูกส่งไปที่ใดและไม่ถูกบันทึก

## วิธีเปิดดู

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ในเครื่อง:

```bash
npx serve .
```

ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ (Kanit, Noto Serif Thai) จาก Google Fonts

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า |
| `style.css` | สไตล์ทั้งหมด (ธีมสีกำหนดด้วยตัวแปร CSS) |
| `app.js` | ข้อมูลเมนู ข้อความ 2 ภาษา และตรรกะของหน้า |
| `assets/logo.png` | ตราสัญลักษณ์ |

## ในหน้ามีอะไร

- **แถบด้านบน (สำหรับพรีวิวเท่านั้น):** สลับแบบ header (A / D / E) สี 5 สี ภาษาไทย/อังกฤษ และปุ่ม "ดูทั้งหมด 15 แบบ"
  ส่วนนี้ไม่ใช่ส่วนของระบบจริง ตอนทำจริงให้เลือกแบบและสีเดียว
- **Header + เมนู:** เมนูย่อยตามระบบเดิม ปุ่มภาษา ปุ่มปรับขนาดตัวอักษร
- **หน้าแรก = เข้าสู่ระบบ:** ชื่อผู้ใช้/รหัสผ่าน, OTP อีเมล (จำลอง), เข้าใช้งานด้วย ThaID (จำลอง), ลืมรหัสผ่าน
- **ลงทะเบียนผู้ใช้ใหม่:** เลือกประเภทผู้ใช้ (โรงเรียน / จังหวัด / เจ้าหน้าที่ สช. ส่วนกลาง) มี 2 แบบให้เลือกเทียบ
  กดส่งแล้วแสดงรหัสคำขอ
- **Footer**

### ลองใช้งาน

- รหัสผ่าน `wrong` = จำลองกรณีรหัสผิด, รหัสผ่านอื่นใด = ผ่านไปขั้น OTP, OTP กรอกเลข 6 หลักอะไรก็ได้
- ในหน้าลงทะเบียนมีปุ่ม "เติมข้อมูลตัวอย่าง" บนแถบพรีวิว

## สิ่งที่ยังเป็นค่าตัวอย่าง / ต้องยืนยัน

- **รูปตราสัญลักษณ์** ตัดมาจากภาพหน้าจอ ความละเอียดต่ำ ควรใช้ไฟล์ต้นฉบับ (PNG/SVG) จากหน่วยงาน
- **QR LINE OpenChat** ใน footer เป็นรูปสุ่ม ไม่ใช่ QR จริง
- **ชื่อหน่วยงาน** ใน header ไม่มีคำว่า "ส่งเสริม" แต่ footer มี (ตามระบบเดิม) ต้องยืนยันชื่อทางการ
- **ปุ่มดาวน์โหลดแบบฟอร์มขอใช้ระบบ** เป็นการจำลอง ต้องมีไฟล์แบบฟอร์มจริง
- **ไอคอน ThaID** เป็นไอคอนที่ออกแบบเอง ต้องใช้ตามแนวทางแบรนด์ของกรมการปกครอง
- **ข้อความประกาศ/ช่องข้อมูลในฟอร์มลงทะเบียน** เป็นข้อเสนอ ต้องยืนยันว่าต้องเก็บข้อมูลอะไรจริง
- **รายชื่อโรงเรียน** ในช่องค้นหามีแค่ 8 แห่งเป็นตัวอย่าง
- **หน้าเมนูอื่น ๆ** (บริการ, คู่มือ, ติดตามคำขอ ฯลฯ) ยังเป็นหน้าว่าง

## แผนถัดไป

พัฒนาจริงด้วย React 19 + TypeScript (frontend), Java Spring Boot 4 (backend),
SQL Server + Redis ตามที่กำหนด โดยใช้ต้นแบบนี้เป็นแบบอ้างอิงหน้าตา
